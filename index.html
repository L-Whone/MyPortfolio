The Problem

When opening multiple menus in game, and closing one, the cursor would lock and be disabled. This affected the player mostly when they died and then paused the game. After closing the pause menu the cursor would disappear on the Death Screen, soft locking the player.

The Approach

To solve this problem, I worked backwards and tried to find out why the problem was happening. I looked through the code to find where all of the menus were enabled. From looking at the code, I figured out that how the cursor was handled was different and separate for each menu. Each menu switched the player’s input map to “UI” and enabled the cursor when opened, and switched the player’s input map to “Player” and disabled the cursor when closed. This meant that if a menu was open on top of another, closing the top menu would result in the Input Map being switched to “Player” and the cursor disappearing even though the player still has a menu open.

My first idea was to count the number of menus open and if there were none, switch the player input map back from “UI” to “Player”, but I could see this having many problems later on, specifically in terms of scalability and flexiblity.

My second idea was to tie the Input Map switching and cursor enabling in a way that would allow the Input Maps to be tracked. I planned to keep track of what Input Maps the player changed to with a Stack system. When I change the Input Map of the player, push the Input Map to a Stack and when I want to switch back to the previous Map, I pop the Stack back.

The Result

This system allowed the menus to stay decoupled and was a more flexible system for switching the player’s Input Maps, because it was all consolidated in one area and could be used in areas other than menus. For each Input Map I could also have specific logic be implemented when switched to, and in this case, that fixed the cursor disabling problem: when the player’s Input Map is switched to “UI” enable the cursor and show it. If the Map is switched to “Player” disable the cursor and hide it.
